# PBLogfileViewer

**An independent log file viewer for PowerBox telemetry log files.**

PBLogfileViewer allows you to analyse telemetry log files in a graphical interface.

This is the public release and community repository for PBLogfileViewer.

## Downloads

Download the latest Windows installer from the [Releases](../../releases) page.

If you would like to submit log files for debugging, please follow the instructions provided when reporting a bug.

**Please do not upload unencrypted log files containing personal or confidential information.**
